### 1.2 カテゴリの体系

| グループ | 項目 |

| 推し | アイドル / アーティスト / VTuber |

**24項目中、他者を伴うものは「人」グループの4項目のみ。** 残り20項目は単独で完結する活動。

### 1.3 記録のインタラクション

- 記録画面に表示されるのは**オンボーディングで選択したカテゴリのみ**。観察したアカウントでは5項目（友達・同僚・副業・睡眠・達成感）だった。
- LPの簡易診断は「もう一度タップで度合いが上がります」と多段階だが、ログイン後の記録画面では段階表現を確認できなかった。
- 「心が揺れた出来事」は任意・折りたたみ。**既定で閉じている**（良い設計）。

### 1.4 柱の判定と表示

- 1日分の記録直後に「**いまのあなたの柱 3本**」と表示。各柱に「🌱 芽・週0.3回」。
- 記録前の状態は「**いまのあなたの柱 0本** / まだ柱がありません。毎日の記録で、あなたを支える柱を育てましょう 🌱」。
- 円グラフには「**はじめの診断を含む表示です。記録を重ねると実データに置き換わります**」という注記が常設。
- ポートフォリオの内訳（観察値）: 達成感 27.1% / 睡眠 20% / 副業 17.1% / 友達 14.3% / 投資 7.1% / 同僚 7.1% / VTuber 7.1%。**記録は1日分のみ**であり、大半がオンボーディング診断由来と推測される。
- 「充足度（週ごとの合計）」は「5ポイント / 30日間」、グラフは2目盛（07/20・07/27）のみ。

### 1.5 AIコーチの実応答

入力: 「最近仕事が忙しくて、あまり眠れていません。」

> お仕事が忙しく、十分に眠れていないのは本当につらいですね。
> データを見ると、現在のポートフォリオで「睡眠」は20%を占めており、週0.3回取り組む大切な心の柱の一つとなっています。
> 今週は、この睡眠の柱を少しだけ育てるために、週に1回だけでも「いつもより10分早く布団に入る」という具体的なアクションを試してみませんか？

- **ユーザーデータの参照は機能している**（20%・週0.3回を引用）
- 応答は3文構成（共感 → データ引用 → 単一アクション提案）で、テンプレート的な骨格が推測される
- 免責表記とよりそいホットライン（0120-279-338）への導線が入力欄下に常設

### 1.8 良くできている点（維持すべきもの）

1. **免責と相談窓口の常設**。フッターとAIコーチ画面の両方にあり、よりそいホットラインの番号まで明記している。国内競合でここまで丁寧なものは多くない。
2. **「心が揺れた出来事」が任意かつ既定で閉じている**。ネガティブ記録の回避（→ 12-evidence #E-07）を前提とした正しい設計。
3. **カスタムカテゴリ＋色の自由度**。設定画面の完成度は高い。
4. **「はじめの診断を含む表示です」の注記**。データの出自を偽っていない点は誠実。
5. **LPでログイン前に体験できる簡易診断**。獲得ファネルとして良い。
6. **記録の軽さ**。タップのみで文章入力を要求しない方針は正しい。
