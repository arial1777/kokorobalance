# 10. 課金設計とB2B計画

**優先度: P3（課金）／長期（B2B）** / 対応課題: C-16

---

## 1. 現状の課金と、その構造的な問題

### 1.1 現状

| プラン | 価格 | 内容 |
|---|---|---|
| Free | ¥0 | 記録 / ポートフォリオ・柱 / 育成提案 / 週間レポート（基本） / **AIコーチ 月3回** |
| Pro | **¥330/月** | Freeの全機能 / AIコーチ無制限 / 週間レポートのAIコメント |

### 1.2 競合との比較

| アプリ | 月額 | 330円との比 |
|---|---|---|
| **ココロバランス** | **330円** | — |
| Awarefy ベーシック | 1,200円（年7,200円） | 3.6倍 |
| Upmind | 1,650円（年6,600円） | 5.0倍 |
| Headspace | 1,650円 | 5.0倍 |
| Calm | 1,950円（年6,500円） | 5.9倍 |
| Awarefy AIパートナー | 約4,000円 | 12倍 |
| こころコンディショナー（朝日新聞社/NEC、東京都採用） | **無料** | — |

出典: E-36, E-46

### 1.3 「安いから守れる」は成立しない

| 事実 | 出典 |
|---|---|
| **Health & Fitness のトライアル→有料転換は35.0%で全カテゴリ最高**。しかし**初回更新継続率は30.3%で全カテゴリ最低**（最高は Utilities 58.1%） | E-13 |
| 380日時点の継続率: **年額 19.9% / 月額 14.2% / 週額 5.5%** | E-13 |
| Health & Fitness は**年額プランが売上の60.6%**を占める | E-13 |
| フリーミアムの有料転換率は一般に **2〜5%** | E-41 |

**解釈**: ヘルスケア領域のユーザーは「よし変わろう」と思って課金し、**変わらなかったので解約します**。入会が最も容易で更新が最も困難な領域であり、**価格の安さでは守れません**。

### 1.4 試算（前提を明示した推定）

手数料15%（小規模事業者プログラム）を控除して実質手取り **約280円/月** とすると:

| DL数 | 課金率3% | 月次実質売上 |
|---|---|---|
| 10万DL | 3,000人 | 約84万円 |
| **100万DL** | 30,000人 | **約840万円** |
| 100万DL・課金率5% | 50,000人 | 約1,400万円 |

参考: **Awarefy は100万DLに6年を要し、累計7.09億円を調達**（E-42）。100万DLは日本のこのカテゴリでほぼ最大手級の規模です。

**結論: 月330円のB2C単体では事業が成立しません。** 価格を上げても成立しませんが、下げても守れません。

## 2. 課金設計の変更

### 2.1 方針

| 方針 | 内容 |
|---|---|
| **① 年額を主導線にする** | 380日継続が年額19.9% vs 月額14.2%。Health&Fitness は年額が売上の60.6% |
| **② 課金理由を「量」から「体験の瞬間」へ** | 「AI無制限」ではなく「揺れる日に備えられる」 |
| **③ 課金訴求の位置を移す** | 上限到達時のモーダルではなく、**ふりかえりで「支えられた」と答えた直後** |
| **④ Free を機能不全にしない** | Free で完結する体験を作る。壊れた無料版は悪評を生む（→ `05` S-15, `08` AI-A-02） |

### 2.2 プラン案

**現行330円を据え置く案（A）と、引き上げる案（B）を併記します。既存課金者への影響があるため意思決定が必要です。**

#### 案A: 価格据え置き＋年額追加（推奨）

| プラン | 価格 | 実質月額 |
|---|---|---|
| Free | ¥0 | — |
| Pro 月額 | **¥330/月**（据え置き） | 330円 |
| **Pro 年額** | **¥2,980/年** | **248円**（25%お得） |

- 既存課金者に影響なし
- 年額を**既定の選択肢として上に置く**（月額を下に小さく）
- リスク: 単価が低いままなので、CACを賄えるチャネルはASOのみ（→ `04#5`）

#### 案B: 引き上げ

| プラン | 価格 | 実質月額 |
|---|---|---|
| Pro 月額 | ¥580/月 | 580円 |
| Pro 年額 | ¥4,800/年 | 400円 |

- 競合（1,200〜1,950円）に対してなお安い
- 既存課金者は**現行価格で継続（グランドファザリング）**が必須
- リスク: 転換率が落ちる。ただし Health&Fitness のトライアル転換35%は価格弾力性がそこまで高くないことを示唆

**推奨: 案A で年額を導入し、3ヶ月の実績を見てから案Bを検討。** 価格変更は1回で済ませたいので、データを取ってから動きます。

### 2.3 Free / Pro の機能境界

`05`〜`09` の仕様と整合させます。

| 機能 | Free | Pro |
|---|---|---|
| 週次点検 | ○ | ○ |
| 柱（3型・承認） | ○ | ○ |
| **揺れ予報（登録・備え・支えリスト・ふりかえり）** | **○（全機能）** | ○ |
| 備えの提案 | ルールベース2件 | ＋ AI生成1件 |
| 壁打ち | **1日1往復**（＋揺れの当日は無制限） | 無制限 |
| 今週のまとめ | ○ | ＋ AIのひとこと |
| 揺れの前の整理（D-3、400字） | × | ○ |
| ふりかえりの言語化 | × | ○ |
| 構成の推移（円グラフ） | ○ | ○ |
| ペア | ○ | ○ |
| データエクスポート | ○ | ○ |

**重要な設計判断: 主機能である揺れ予報を Free で全開放します。**

理由: 課金は「体験の後」に来なければなりません。主機能を有料にすると、価値を知る前に判断を迫ることになり、現行の「AIコーチ月3回」と同じ失敗を繰り返します。**Pro は「深さ」を売ります**（→ `08#6`）。

### 2.4 課金訴求のタイミング

| # | タイミング | 訴求 | 強度 |
|---|---|---|---|
| **1（最重要）** | ふりかえりで `was_supported = yes` を選んだ直後 | 「次の揺れる日には、もっと踏み込んだ整理もできます」 | 中（1画面、スキップ可） |
| 2 | 揺れの当日に壁打ちを3往復以上使った翌日 | 「昨日のような日に、いつでも話せます」 | 中 |
| 3 | 壁打ちの1日上限到達時 | 最下部に1行のみ（→ `08#5.3`） | **弱** |
| 4 | 週次点検を4回完了した時 | 「今週のまとめに、ひとことを添えられます」 | 弱 |
| 5 | 設定画面 | 常設 | — |

**禁止**

| 禁止 | 理由 |
|---|---|
| モーダルで被せる課金訴求 | muute のレビュー「有料画面を閉じる**右上のバツボタンの表示が薄過ぎて気がつきにくい。無料と誤解しかねない**」（E-09）— ダークパターンは即座に評価を落とす |
| 後から無料機能を有料化する | Upmind のレビュー「**スリープストーリーの一部コンテンツがロックされて聴けなくなった**」（E-09） |
| 課金前に制限を明示しない | Awarefy のレビュー「年間契約をしてしまったのですが（中略）**覚えていてくれるわけではありません**」（E-09） |
| プッシュ通知での課金訴求 | 通知を広告に使うと全通知の信頼が落ちる（→ `04#4.1`） |
| 揺れイベント当日の課金訴求 | 最も弱っている日に売らない |

### 2.5 課金前の明示（必須）

購入画面に**制限を先に書きます**。

```
Pro でできること
  ・壁打ちが、いつでも
  ・揺れる日の3日前に、これまでのふりかえりを踏まえた整理が届く
  ・週のまとめに、ひとことが添えられる

Pro でも できないこと
  ・壁打ちは、これまでの会話を全部は覚えていません
    （直近4週分の要約を引き継ぎます）
  ・医療的な相談には答えられません
  ・危機的な状況では、窓口をご案内します
```

**「できないこと」を先に書くアプリは、この市場にほぼ存在しません。** 競合レビューの不満の大半が「課金前に知らされなかった」であることを踏まえた差別化です。

### 2.6 IAP（アプリ内課金）

`04` でストア掲載する際、Apple / Google の IAP が必要になります。

| 項目 | 方針 |
|---|---|
| 手数料 | 小規模事業者プログラム（15%）の適用を申請 |
| 価格の整合 | Web（Stripe）とアプリ（IAP）で**同一価格**にする。IAP を高くすると混乱する |
| IAP 実装前 | **アプリ内に外部課金への導線を出さない**（→ `04` D-A-08） |
| 既存 Stripe 課金者 | アプリでも Pro として認識されること（`Entitlement.source` で判別） |
| 解約 | ストア経由の解約手順をアプリ内に明記（隠さない） |

## 3. B2B計画

### 3.1 なぜB2Bが必要か

**日本のB2C独立プレイヤーは、ほぼ全滅しています。**

| プレイヤー | 結末 | 出典 |
|---|---|---|
| **cotree**（カウンセラー220名、累計11万件） | **2025年3月1日付でJMDCに吸収合併され法人消滅** | E-37 |
| **muute**（150万DL） | **2025年11月、日本生命が完全子会社化**。社名を Nissay MIRAIQA に変更 | E-37 |
| **emol**（25万DL、うち約8割が女性） | B2Cから法人向け・精神疾患DTxへピボット | E-37 |
| **FiNC** | 2019年12月期 純損失47.2億円、翌期25.1億円・債務超過、減資反復 | E-37 |
| **Awarefy** | 継続中。ただし100万DLに6年＋累計調達7.09億円 | E-42 |
| **Kintsugi**（$30M・7年・臨床バリデート済み・FDA De Novo直前・日本で普及） | **2026年2月に廃業。** 「ヘルスケアAIの構築はスタートアップには財務的に持続不能」 | E-43 |
| **BetterHelp**（世界最大級のD2C） | 2026年通期売上見通し **前年比 −12.7%〜−19%** | E-44 |

一方でB2B側:

| 事実 | 出典 |
|---|---|
| 法人向けヘルスケアソリューション市場: **2023年度 258.1億円 → 2024年度 325.3億円 → 2028年度 806.5億円、CAGR 25.6%** | E-38 |
| **2028年4月1日、50人未満事業場のストレスチェックが義務化**（改正労働安全衛生法、2025年5月公布） | E-22 |
| 50人未満の現在の実施率は **34.6%**（50人以上は81.7〜90%） | E-50 |
| メンタルヘルスは**7年連続で最も資金が集まる臨床領域**（米国） | E-45 |

### 3.2 ただし幻想を持たない

**「法人だから高く売れる」は成立しません。**

| 事実 | 出典 |
|---|---|
| ストレスチェック外部委託の相場: **Web受検 200〜700円/人**、平均300〜600円/人 | E-39 |
| 月額型サービスは **1名あたり数百円/月**（月額100円から導入できるものも存在） | E-39 |
| 50人規模で年間2〜10万円、100人規模で3〜10万円前後 | E-39 |

**単価は個人課金の330円と大差ありません。** 違うのは以下の3点です。

| B2Bの本当の利点 | 内容 |
|---|---|
| **獲得効率** | 1商談で数十〜数千人分の契約が取れる。CAC $150〜$500 の壁を回避できる |
| **予測可能性** | 年次契約。解約が予測でき、キャッシュフローが読める |
| **購買トリガー** | 2028年4月という**日付が確定した法的義務** |

また、**参入障壁も高い**ことを認識してください。商流が「産業医・EAP・保険会社・人事コンサル」に握られており、cotree が JMDC に吸収され muute が日本生命に買収されたのは、この構造の帰結と読めます。

### 3.3 売り物の設計

**ストレスチェックそのものを売るのではありません。**（既存ベンダーが200〜700円/人で提供しており、価格競争に勝てません。）

**「柱」を、健康経営における "つながり・居場所" の指標として売ります。**

| 売る対象 | 内容 |
|---|---|
| **組織向けレポート** | 部署単位で「職場以外の柱を持っている人の割合」「職場を居場所として挙げた人の割合」を集計（**個人は特定できない粒度で**） |
| **転機のサポート** | 異動・組織変更・繁忙期の前に、対象部署へ揺れ予報を配信（`05` の `work_*` テンプレはこのために設計されている） |
| **既存ストレスチェックの補完** | 既存ベンダーのリプレイスではなく、**その後のフォロー**として位置づける。競合しない |

### 3.4 差別化の根拠

VC の投資基準は明確です（E-35）。$20M超のラウンドに共通する3特性:

1. **独自の臨床データとエビデンス**
2. **B2B / B2B2C のエコノミクス**（消費者サブスクではない）
3. **規制上の防御性**

そして「**We don't invest in an app without evidence of efficacy**（有効性のエビデンスがないアプリには投資しない）」。

**B2Bで売れる条件として、以下が資産になります。**

| 資産 | 参照 |
|---|---|
| **セーフティの測定体制**（偽陰性の抽出レビュー、資格保持者による月次レビュー） | `03#6` |
| **エビデンスに基づく設計**（Social Identity Approach、Groups 4 Health） | `07#1.2` |
| **独自スコアを作っていないこと** | `07#6`。妥当性の批判を受けない |
| **医療的主張をしていないこと** | `03#7` |

**企業は「安全でないツールを従業員に配った」責任を負います。** `03` の体制は、コストではなく販売条件です。

### 3.5 時系列計画

| 時期 | やること |
|---|---|
| 2026年下期 | B2Cで `03`〜`08` を実装し、**セーフティの測定体制を稼働させる**（販売条件の整備） |
| 2027年上期 | 1〜3社のパイロット（無償または実費）。組織レポートのプロトタイプを作る。**産業医・EAP事業者との接点を作る** |
| 2027年下期 | パイロットの結果を事例化。50人未満事業場向けのパッケージを設計。**既存ストレスチェックベンダーとの提携を模索**（リプレイスではなく補完で入る） |
| **2028年4月** | **義務化。** 準備が済んでいる状態で迎える |
| 2028年以降 | 大学・自治体への展開（同じ売り物が使える） |

### 3.6 B2Bで実装が必要になるもの（現時点では作らない）

| 項目 | 備考 |
|---|---|
| 組織アカウント・シート管理 | `Entitlement.source = b2b_seat` を予め定義済み（→ `02#2.10`） |
| 集計レポート（個人非特定） | 最小集計単位を**10名以上**に固定する等の設計が必要 |
| SSO（SAML/OIDC） | 企業導入の必須要件になりやすい |
| データの所在・保持ポリシーの明文化 | 企業のセキュリティチェックシート対応 |
| **従業員が「会社に見られている」と感じない設計** | 最大の失敗要因。**個人データは絶対に会社に渡さない**ことを従業員向けに明示する |

> **B2B導入の失敗要因は「従業員への周知不足」「社内推進担当者の不在」、そして最も多いのが「企業の想定と従業員の実際のニーズのズレ」**です（E-51）。会社が導入しても従業員が使わなければ更新されません。**B2Cとしての品質が、B2Bの前提条件です。**

## 4. 受入基準

| # | 基準 |
|---|---|
| M-A-01 | 年額プランが購入でき、購入画面で**年額が既定の選択肢**として上に表示される |

| M-A-08 | 既存 Stripe 課金者がアプリで Pro として認識される |
| M-A-09 | 価格改定を行う場合、既存課金者が現行価格で継続される |
| M-A-10 | 解約手順がアプリ内に明記されている |

## 5. 計測

| 指標 | 定義 | 目標 |
|---|---|---|
| **年額比率** | 新規課金のうち年額の割合 | **60%** |
| インストール→課金 | 全体の転換率 | 3%（フリーミアム標準の上限） |
| **初回更新率** | 初回の更新に至った割合 | **40%**（Health&Fitness の30.3%を上回る） |
| 380日継続率 | 年額 / 月額それぞれ | 年額25% / 月額18%（業界19.9% / 14.2%） |
| 訴求経路別の転換 | §2.4 の #1〜#5 それぞれの転換率 | 観測。#1 が最大になることを確認 |
| 解約理由 | 解約時の任意アンケート（1問、スキップ可） | 観測 |
| ARPU | 課金者あたり月次収益 | 観測 |
| **返金・チャージバック率** | | 1%未満（ダークパターンがないことの検証） |
