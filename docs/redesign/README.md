# ココロバランス 再設計ドキュメント

kokorobalance.app の**コンセプト再設計と機能仕様**をまとめたドキュメント群です。

## このドキュメントの前提

- **ソースコードは参照していません。** 根拠は (a) 2026-08-01 に実機（本番環境）を Google ログインして外部から観察した記録、(b) 公開されている市場データ・学術文献のみです。
- したがって本書は**実装非依存の要件仕様書**です。特定のフレームワーク・DB・ライブラリを前提にしていません。データモデルは論理モデルとして記述し、物理設計は実装側の判断に委ねます。
- 既存実装との差分（マイグレーション）は、現状の内部構造が不明なため**推定を含みます**。`00-current-state.md` に「観察できた事実」と「推定」を分けて記載しています。
- 数値・引用はすべて `12-evidence.md` の台帳に出典を集約しています。**社外資料に転記する前に一次ソースを再確認してください。**

## 未解決の宿題（意思決定が必要）

1. **名称の商標・SEO衝突**: 「ココロバランス」は一般社団法人ココロバランス研究所（kokorobalance.jp）が使用中。法務確認と、必要なら名称変更の判断。→ `01-concept.md#naming`
2. **プラン価格の変更可否**: 既存課金者への影響。→ `10-pricing-b2b.md`
3. **既存ユーザーの記録データの取り扱い**: 日次記録から週次点検への移行時に過去データをどう扱うか。→ `06-spec-weekly-check.md#migration`
4. **医療機器該当性の見解**: 「壁打ち」の応答範囲について、薬機法上のプログラム医療機器（SaMD）該当性の整理。→ `03-spec-safety.md#regulatory`
